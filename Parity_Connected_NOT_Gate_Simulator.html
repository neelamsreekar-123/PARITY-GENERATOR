01 / The big idea

What is a parity bit?

+1

One extra bit

A parity bit is added to a group of data bits. It is selected so the total number of 1s follows a chosen rule: even or odd.

0 ↔ 1

Why use it?

When data is received, a parity check can reveal some transmission errors. It does not identify which bit is wrong or correct the error.

Even parity means an even total; odd parity means an odd total.

02 / The logic gate

XOR: the parity workhorse

A ⊕ B

XOR means “exclusive OR.” Its output is 1 when the two inputs are different, and 0 when they are the same.

ABA ⊕ B
000
011
101
110

Why XOR is useful

Each time another 1 is added, XOR toggles the result. Therefore, XOR of all data bits is 1 when the number of 1s is odd, and 0 when the number of 1s is even.

Memory trick: XOR gives 1 for an odd count of 1s.

03 / Generator A

Even parity generator

RULE: TOTAL 1s MUST BE EVEN

P = D3 ⊕ D2 ⊕ D1 ⊕ D0

If the data already contains an even number of 1s, P = 0. If it contains an odd number, P = 1 so the final count becomes even.

Example: 0111

There are three 1s in the data. Three is odd, so choose P = 1.

0111 | 1

Now the full word has four 1s — an even count.

Circuit idea: combine pairs of bits with XOR gates, then XOR those intermediate outputs to get P.
04 / Generator B

Odd parity generator

RULE: TOTAL 1s MUST BE ODD

P = ¬(D3 ⊕ D2 ⊕ D1 ⊕ D0)

Odd parity is the inverse of the even-parity output. A NOT gate flips the XOR result.

Example: 0111

There are three 1s already, which is odd, so choose P = 0.

0111 | 0

The full word still has three 1s — an odd count.

The symbol ¬ means NOT (inversion): 0 becomes 1 and 1 becomes 0.

07 / Check the receiver

Can parity detect an error?

Try changing the received bits

Starting example: data 1011 with even parity bit 1, giving 10111 (five bits, four 1s).

Important limitation

A single flipped bit changes even parity to odd, so the receiver notices a mismatch. But if two bits flip, the total parity can remain valid and the error may be missed.

Parity detects many errors, especially any odd number of bit flips, but it cannot correct errors and may miss an even number of flips.
08 / Wrap-up

Remember these four points

01. Parity bit

An extra bit used to check whether the total count of 1s follows a rule.

02. XOR gate

XOR of the data bits is 1 when there is an odd number of 1s.

03. Even vs odd

Even parity uses the XOR output; odd parity uses its inverse.

04. Error checking

Parity can detect certain errors, but cannot correct them and can miss two-bit flips.

Closing line: “By using XOR gates, we can generate a parity bit efficiently and add a simple error-detection check to digital data.”
